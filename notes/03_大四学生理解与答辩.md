# 大四学生层面的项目理解与答辩准备

下面是一份可理解、可复算、可改写的学习底稿，不是对 A、B 真实经历的代写证明。使用者应把实际做过的核验、自己的疑问和修改补入个人记录。

## 1. 我们到底在研究什么

这个项目的数学问题可以表述为：**在同一 PMSM 电流初值问题上，步长、方法阶数和稳定域怎样共同决定计算是否可信？**

电机是应用背景，核心不是让电流曲线“看起来像电机”，而是形成证据链：先说明模型如何产生，再说明算法近似了什么，然后测出误差，最后用稳定性解释成功和失败。

第一周把以前学过的微分方程、线性代数和 Taylor 展开连接起来：微分方程给瞬时变化率，Jacobian 把扰动分解成增长/衰减与振荡模式，Euler 把连续演化变成可计算递推。第二周进一步认识到，高阶精度、数值稳定和非线性方程求解分别解决不同问题。

## 2. 对模型的理解应该达到什么程度

看到

$$\dot i_q=(u_q-Ri_q-\omega_eL_di_d-\omega_e\psi_f)/L_q,$$

应能解释：外加电压推动电流变化；电阻项耗散；d-q 耦合来自旋转坐标；永磁体产生反电动势；电感把净电压转换成电流变化率。每项单位都必须一致。

更重要的是承认简化的作用。这里速度是给定量，所以状态只有两个电流。我们不能用这份代码说明电机从静止自行加速到额定转速；那需要机械动力学与负载参数。若加入机械角速度 ω_m，典型扩展为

$$J_m\dot\omega_m=T_e-T_L-B_m\omega_m,\quad
T_e=\frac32p[\psi_fi_q+(L_d-L_q)i_di_q],\quad\omega_e=p\omega_m.$$

这里 J_m 是转动惯量，不是 Jacobian。出现 ω_m i_d、ω_m i_q 等乘积后，扩展系统需要重新推导三状态 Jacobian、核对参数和参考解；本包没有把这项扩展当作已完成工作。

## 3. 有解析解，还需要数值方法吗

对于本包的恒参数、恒输入、恒速线性模型，确实存在矩阵指数解。如果唯一目标只是求这一条曲线，可以直接用它。

课程要求比较数值方法时，这个模型的价值恰好是能提供可靠的校准对象。我们可以知道误差来自哪里，而不是同时猜模型和算法。之后考虑变速、饱和或控制器时，仍可复用已检验的求解器；但不能在没有扩展模型与证据时声称解决了这些情况。

“能算出来”不是选题的全部价值。更有意义的研究问题是：为什么同样的电机方程用 Euler 的某个步长会数值增长，而连续模型的扰动明明衰减？

## 4. 一段可自己手算的 PMSM 更新

使用本包基准，初值为零，f(0,y₀)=(0,2500)^T A/s。取 h=10^-4 s，则

$$y_1=y_0+hf(0,y_0)=(0,0.25)^T\ \mathrm A.$$

第二步使用旧状态 y₁：

$$\dot i_d=\frac{1000\times0.004\times0.25}{0.003}=333.333333\ \mathrm{A/s},$$
$$\dot i_q=\frac{60-0.5\times0.25-50}{0.004}=2468.75\ \mathrm{A/s}.$$

因此

$$y_2=(0.0333333333,\;0.496875)^T\ \mathrm A.$$

这两步检查状态顺序、单位和符号，不能替代长期误差测试，但能很快定位把毫亨当亨、把毫秒当秒或原地更新分量的错误。

## 5. 第一周最重要的理解变化

局部误差 O(h²) 不等于整体二阶精度。固定 T 下大约走 T/h 步，每步注入的新误差还会传播，最终形成 O(h) 全局误差。这个认识要能用误差递推式说明，不能只背结论。

同样，观察阶接近 1 也不是模型正确的证明：如果两份程序共享一个符号错误，它们可能给出一致但错误的物理问题。因此既要检查公式与单位，也要检查独立特殊情形和误差细化。

本次材料核对中，Logistic 讲义第二步的算术笔误就体现这种原则：参考材料应与数学计算相互检查，不应为了“匹配答案”改坏代码。

## 6. 第二周最重要的理解变化

高阶方法减少截断误差，但稳定域仍然有限。PMSM 基准特征值含较大虚部，Euler 的可用步长由复平面几何决定，不能只用实负特征值公式 2/|λ|。

隐式 Euler 覆盖整个左半平面，却只有一阶精度。例如对 y'=-1000y、h=0.01，其一步值是 1/11，而真解是 e^-10；两者都衰减，但数值很不一样。“稳定”并不等于“好到可以用”。

本包恒速 PMSM 的 Newton 一次修正，是因为残差为仿射函数。真正的非线性困难在 RC 二极管例中表现为指数项过冲。阻尼改变的是求根路径，不是原始隐式方程，也不是自动提升时间离散精度。

## 7. 把代数误差和时间误差算给别人看

课程标量例：y'=-y²、y_n=1、h=0.5。隐式方程为

$$F(w)=w-1+\tfrac12w^2=0,\qquad F'(w)=1+w.$$

从 w⁽⁰⁾=1 出发，

$$w^{(1)}=1-\frac{1/2}{2}=3/4,$$
$$w^{(2)}=\frac34-\frac{1/32}{7/4}=\frac{41}{56}\approx0.732142857.$$

隐式方程的正根 w*=√3−1≈0.732050808，而微分方程真解 y(0.5)=2/3。因此

$$w^{(2)}-y(0.5)=[w^{(2)}-w^*]+[w^*-y(0.5)].$$

第一项约 9.205×10^-5，是剩余 Newton 误差；第二项约 0.0653841，是时间离散误差。继续 Newton 只能消除第一项，减小 h 才能系统改善第二项。这是答辩时最有说明力的具体例子之一。

## 8. 我们能提出哪些有边界的结论

从本包实际实验可以讨论：三种方法在此基准达到预期阶；Euler 与 RK4 的谱边界能够预测常系数扰动的增长；局部容差收紧改善了这组自适应轨迹；RC 的阻尼减少了指定设置下的 Newton 修正次数。

不应据此写：任何 PMSM 都强刚性；隐式 Euler 任意 h 都准确；Newton 从任意初猜必收敛；局部误差小于容差就保证全局误差小于相同容差；某方法必然比另一方法快。效率结论需要在相同参考误差目标下统计实际成本，后续可以据课程要求补全。

## 9. 答辩自检

| 可能的问题 | 应能说明的要点 |
|---|---|
| 为什么状态只放两种电流？ | 速度外部给定；这是电气子系统，机械模型不在当前范围 |
| d-q 两个耦合项为什么异号？ | 坐标旋转矩阵的反对称结构与统一的 Park 变换约定 |
| 为什么平衡电流不一定为零？ | 平衡是导数为零，电压、反电动势与电阻可以在非零电流处平衡 |
| 如何证明解存在且唯一？ | 仿射 f 对状态全局 Lipschitz；常系数线性系统全局存在 |
| 为什么 L_d≠L_q 不代表非线性？ | 系数仍为常数，电流只一次出现 |
| Euler 的复特征值界怎么得到？ | 展开 (1−αh)²+(βh)²≤1，解出 2α/(α²+β²) |
| 为什么 RK4 四阶不是看四次函数值？ | 阶条件匹配 Taylor 的不同微分结构；四阶段本身不足以保证四阶 |
| 为什么要看整个轨迹的误差？ | 末时刻接近平衡可能掩盖之前很大的暂态与相位误差 |
| 为什么 Newton 用 I−hJ_f？ | 对未知新状态 w 微分完整残差 F=w−y_n−hf(t_n+h,w) |
| 自适应拒绝之后做什么？ | t、y 保持原值，以更小 h 从同一状态重算三个子步 |
| 误差估计分母为何是 2^p−1？ | 两个半步缺陷加和的主系数为粗步的 1/2^p |
| 我如何确认是自己的理解？ | 不看代码重推一个关键公式，手算一例，改参数预测变化，再运行检验 |
